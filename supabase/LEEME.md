# Base de datos

DN usa la base **compartida** de la Plataforma Automotoras (un solo proyecto de Supabase para todas las automotoras).
El esquema y las reglas están en `~/Proyectos/plataforma-automotoras` (repo `matias-bermudez/plataforma-automotoras`).
No cambiar el esquema desde acá.

En `js/config.js`, `concesionaria: 'dn'` es el id de DN en esa base.
